# REVIEW & CHANGELOG SYSTEM v1

## Review

Każdy review zapisuje:

- wersję,
- kryteria,
- wynik,
- hard fails,
- trzy największe problemy,
- jedną instrukcję następnej rundy,
- decyzję PASS / REVISE / REJECT.

## Changelog

Każda zmiana systemowa zapisuje:

- co,
- dlaczego,
- wpływ,
- pliki zależne,
- rollback,
- status.
