# MOTION SYSTEM v0.1

## Zasady

- ruch wyjaśnia zmianę stanu,
- najpierw funkcja, potem charakter,
- jedna główna trajektoria,
- preferuj 150–250 ms dla mikrointerakcji,
- 250–450 ms dla zmian sekcji,
- ogranicz ruch przy preferencji reduced motion,
- nie animuj wszystkiego równocześnie.

## Zakazane

- dekoracyjne pulsowanie,
- parallax bez funkcji,
- ruch uniemożliwiający odczyt,
- automatyczne karuzele bez kontroli.
