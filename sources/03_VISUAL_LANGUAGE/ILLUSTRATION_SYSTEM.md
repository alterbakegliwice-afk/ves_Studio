# ILLUSTRATION SYSTEM v0.1

## Zasada

Styl ilustracji opisuj parametrami, nie nazwiskiem artysty:

- geometria,
- poziom uproszczenia,
- rodzaj linii,
- paleta,
- tekstura,
- perspektywa,
- rytm,
- poziom humoru,
- funkcja.

## Anti-style

Nie naśladuj dosłownie charakterystycznego stylu żyjącego twórcy. Łącz ogólne zasady i projektuj własny język marki.
